## Проект: литология по данным ГИС

[![Планшет скважины с прогнозом фаций](https://raw.githubusercontent.com/xarebovdavid/well-log-facies-web/main/docs/screenshot.jpg)](https://xarebovdavid.github.io/well-log-facies-web/)

**[Открыть сайт](https://xarebovdavid.github.io/well-log-facies-web/)** · **[Код](https://github.com/xarebovdavid/well-log-facies-web)**

Веб-сервис для геофизиков: загружаешь каротаж скважины — получаешь планшет с прогнозом фаций,
уверенностью модели и сомнительными интервалами.

- Модель машинного обучения (CatBoost) работает прямо в браузере — данные скважины никуда не отправляются.
- Читает CSV, Excel и LAS, сам распознаёт названия столбцов.
- Геолог может не согласиться с моделью, поправить фацию и скачать итоговую разметку.

Командный проект: модель и исследование данных — команда, веб-сервис — моя часть.
