### 🪨 Литология по данным ГИС

[![Планшет скважины с прогнозом фаций](https://raw.githubusercontent.com/xarebovdavid/well-log-facies-web/main/docs/screenshot.jpg)](https://xarebovdavid.github.io/well-log-facies-web/)

**[Открыть сайт](https://xarebovdavid.github.io/well-log-facies-web/)** · **[Код](https://github.com/xarebovdavid/well-log-facies-web)**

Веб-сервис для геофизиков: загружаешь каротаж скважины — получаешь планшет с прогнозом фаций,
уверенностью модели и сомнительными интервалами.

- Модель машинного обучения (CatBoost) работает прямо в браузере — данные скважины никуда не отправляются.
- Читает CSV, Excel и LAS, сам распознаёт названия столбцов.
- Геолог может не согласиться с моделью, поправить фацию и скачать итоговую разметку.

Командный проект: модель и исследование данных — команда, веб-сервис — моя часть.

### 🛢️ Буровой калькулятор

[![Буровой калькулятор — объёмы скважины](https://raw.githubusercontent.com/xarebovdavid/drilling-calculator/main/docs/screenshot.png)](https://xarebovdavid.github.io/drilling-calculator/)

**[Открыть калькулятор](https://xarebovdavid.github.io/drilling-calculator/)** · **[Код](https://github.com/xarebovdavid/drilling-calculator)**

Типовые расчёты технологии бурения в браузере: гидростатическое давление, ЭЦП, плотность раствора
по пластовому давлению с нормативной репрессией, объёмы скважины по интервалам конструкции,
время циркуляции, скорость в кольцевом пространстве, вес колонны в растворе.

- Каждый расчёт показывает формулу с подставленными числами — результат можно проверить вручную.
- Формулы покрыты контрольными примерами, которые сверяются независимым скриптом на Python.
